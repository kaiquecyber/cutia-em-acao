# 🐾 Cutia em Ação

Uma página web dedicada à apresentação da cutia (*Dasyprocta*), um mamífero roedor encontrado nas Américas. O projeto combina informações sobre o animal com elementos visuais desenvolvidos em HTML5 e CSS3.

## 📌 Sobre o projeto

O **Cutia em Ação** é um projeto de desenvolvimento web que apresenta características da cutia por meio de uma interface visual com imagens, textos informativos e um fundo inspirado em seu ambiente natural.

O objetivo é praticar os fundamentos do desenvolvimento front-end, explorando a estruturação de páginas e a estilização de elementos com CSS.

## ✨ Funcionalidades

- Apresentação de informações sobre a cutia.
- Exibição de imagem do animal.
- Cenário visual com imagem de fundo.
- Estilização de textos e elementos utilizando CSS.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura e organização do conteúdo.
- **CSS3** — estilização, cores, espaçamentos e composição visual.
